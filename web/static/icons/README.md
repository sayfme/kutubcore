# Icons (SVG, stroke style)

24×24 viewBox, stroke `currentColor`, no text. Used via
`<img class="ic" src="/static/icons/<name>.svg" alt="" aria-hidden="true">`.
Sets: app chrome (logo, search, sign-in/out, star, plus, file, store),
sections (book, library, target, shelf, pen), statuses (online, offline).
